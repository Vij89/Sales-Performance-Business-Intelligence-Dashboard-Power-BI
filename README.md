# 📊 Sales Performance & Business Intelligence Dashboard – Power BI

## 📌 Project Overview
An interactive Sales Performance Dashboard developed using Microsoft Power BI to present business performance through KPIs and data visualizations.

The dashboard focuses on analyzing sales, profitability, product categories, customer segments and geographical performance.

## 📈 Dashboard Preview
The PDF below contains two dashboard pages showcasing different analytical views and visualizations.

**[View Power BI Sales Dashboard PDF](PowerBI_Sales_Dashboard_Portfolio.pdf)**

## 🔍 Key Analysis
- Total Sales and Total Profit Monitoring
- Category-wise and Sub-Category-wise Sales Analysis
- Segment-wise Sales Performance
- Region and State-wise Analysis
- Year-wise Sales Trends
- Sales and Profit Relationship Analysis
- Profit Movement Analysis using Waterfall Charts

## 📊 Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Discount
- Order Count
- Average Sales

## 🛠️ Tools & Technologies
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Data Modeling
- Data Visualization

## 📉 Visualizations Used
- KPI Cards
- Scatter Chart
- Waterfall Chart
- Line Chart
- Area Chart
- Donut Chart
- Stacked Bar Chart

## 🎯 Business Objective
To transform sales data into meaningful business insights, monitor key performance indicators, identify sales trends and support data-driven business decisions.
